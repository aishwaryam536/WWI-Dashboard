# WWI Power BI Dashboard

## Project Overview
An interactive Power BI dashboard created using the Worldwide Importers dataset.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Dashboard Features
- Total Including Tax
- Total Profit
- Most Profitable Product
- Profit Trend
- Profit by Sales Territory
- Geographical Map
- Employee Details
- Drill-through Analysis
- Date Filtering
